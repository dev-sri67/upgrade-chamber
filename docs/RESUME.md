Deployment archives remain allowlisted and exclude `.env`, `.local`, credentials, tests, and unrelated files. The local suite passed 52 tests.

The read-only-root staging blocker recorded in the previous handoff is fixed. Commits `c54ad64` and `31ae613` replaced all eight `put_archive` staging sites and both `get_archive` readers in `src/upgrade_chamber/runner.py` with a bounded exec transport. Staged input is written to the standard input of a fixed `python -I -c` script as an 8-byte little-endian length frame, and the script opens its target with `O_EXCL`, rejecting overwrites and symlinks; the attempt input is unpacked by a tarfile data-filter extraction exec; exports are read back as regular files opened with `O_NOFOLLOW` and demultiplexed by a `_FrameDemuxer` that parses Docker's non-TTY stream framing (8-byte `>BxxxL` headers) before validation. Every Docker and socket call is bounded by a monotonic deadline, and `DeadlineExceeded` maps to a timed-out status with a guarded kill, log capture, and observed removal.
